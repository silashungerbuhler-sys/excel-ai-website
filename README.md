# excel-ai-website
Excel AI entwickelt eine Desktop-Software zur Analyse von Excel- und CSV-Dateien. Nutzer können ihre Tabellen hochladen, Fragen zu den Daten in natürlicher Sprache stellen, Berechnungen durchführen, Daten vergleichen und Ergebnisse visualisieren. Die Software wird als monatliches Abonnement für CHF 8.99 angeboten.
